## 对外交付

把接入方选中的指南与对应版本的示例源码一起发出。保留仓库目录结构，让指南里的代码链接可直接打开。接入方应收到 `.env.example` 配置模板，真实认证地址、测试账号和客户端凭据由平台管理员分别交付。打包前检查实际 `.env`、运行日志和带登录回调参数的截图，发布包只包含接入需要的文件。
