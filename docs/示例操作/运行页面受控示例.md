# 运行页面受控示例

用一个账号验证两种结果：有权限的订单页能进入，无权限的报表页被拒绝。

## 1. 准备客户端和页面

按[快速运行](示例客户端快速运行.md)准备工具和客户端凭据。让平台管理员选择页面受控，示例配置填写 `SSO_AUTH_MODE=PAGE_CONTROLLED` 和 `SSO_REQUIRE_EXTERNAL_ACCOUNT=false`。用本机运行时，系统地址为 `http://localhost:18085`，固定回调路径为 `/api/auth/callback`。

| 页面 | 页面编码 | 路径 | 权限标识示例 |
| --- | --- | --- | --- |
| 订单查询 | `B_PAGE_01` | `/pages/orders` | `b:orders:view` |
| 经营报表 | `B_PAGE_02` | `/pages/reports` | `b:reports:view` |
| 运维控制台 | `B_PAGE_03` | `/pages/operations` | `b:operations:view` |

让平台管理员按表登记页面。角色授权时应选中平台实际生成或已登记的权限项。准备一个普通测试账号，先只给订单页权限。

## 2. 分别访问两个页面

1. 打开示例首页，点击【订单查询】。登录后应能进入订单页。刷新时，示例后端继续检查订单页授权。
2. 返回首页并点击【经营报表】。访问应被拒绝，即使示例首页仍显示报表入口。直接输入 `/pages/reports` 也应得到同样结果。
3. 让管理员给该账号增加报表权限，再从报表页重新发起授权。返回首页后，两个页面都授权有效时，首页通常显示两组有效访问令牌。
4. 让管理员取消订单页权限，再刷新订单页。下一次请求应被拒绝，已打开的页面内容由刷新或后续请求更新。
5. 点击首页【退出 B 系统】或【退出整个服务】，对照两种退出后再次访问业务页时的差异。

要保护自己的页面和数据接口，按[页面受控接入指南](../外部系统接入/页面受控接入指南.md)实施。
