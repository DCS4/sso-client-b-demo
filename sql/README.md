# 演示环境数据库脚本

这些脚本供平台管理员在隔离的演示环境中准备数据。示例客户端把登录状态和授权保存在后端会话中，运行示例无需额外建库。真实客户端若已有用户表和权限数据，按所选接入指南使用自己的数据。

| 认证模式 | 演示脚本 | 准备内容 |
| --- | --- | --- |
| 普通单点登录 `SSO_ONLY` | [普通单点登录演示脚本](普通单点登录_SSO_ONLY.sql) | 普通单点登录客户端登记 |
| 页面受控 `PAGE_CONTROLLED` | [页面受控演示脚本](页面受控_PAGE_CONTROLLED.sql) | 客户端、三个演示页面和相应角色权限 |

两份脚本使用相同的演示客户端登记记录。选择其中一份准备演示环境即可。切换模式时，可由平台管理员调整该环境的登记信息，并同步修改示例 `.env` 中的模式。页面受控脚本将演示页面权限分配给管理员角色。若要验证“有权限进入订单页、无权限进入报表页”，请使用普通测试角色，按需分别授权。

脚本中的密钥校验值须与客户端后端使用的明文密钥对应。需要取得新密钥时，由平台管理员通过管理端创建客户端或重置密钥，再将一次性展示的明文交给客户端后端负责人。配置方法见[配置与访问地址](../docs/原理与参考/配置与访问地址.md#客户端密钥由谁保管)。

接入方首次运行可看[示例客户端快速运行](../docs/示例操作/示例客户端快速运行.md)。改造自己的业务系统时，请选择[对应接入指南](../docs/外部系统接入指南.md)。
