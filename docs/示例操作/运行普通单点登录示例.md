# 运行普通单点登录示例

用示例的订单页和报表页观察普通单点登录。完成后，你应能看到同一个平台账号访问多个示例页面，并理解退出本系统与退出平台的区别。

1. 请平台管理员将示例客户端登记为普通单点登录，确认外部账号必绑关闭。按[快速运行](示例客户端快速运行.md)填写客户端凭据、认证地址和回调，并使用 `SSO_AUTH_MODE=SSO_ONLY` 和 `SSO_REQUIRE_EXTERNAL_ACCOUNT=false`。这个示例无需在平台登记订单或报表权限。
2. 启动示例，打开首页，点击【订单查询】。平台登录成功后应进入订单页。使用已经登录平台的浏览器时，可能直接返回业务页。
3. 回到首页，点击【经营报表】。原有授权仍有效时，报表页会复用它。返回首页后，有效访问令牌数通常仍为 1。刷新任意业务页面，后端会再次核验当前授权。
4. 点【退出 B 系统】，再访问订单页。平台登录仍有效时，浏览器可以取得新授权并回到订单页。随后用【退出整个服务】退出，下次进入订单页应重新看到平台登录页。

想观察请求细节时，可在浏览器“网络”面板查看平台授权地址。普通单点登录请求省略 `page_code`（页面编码），首页显示的演示页面编码只用于本地目录。示例页面用于展示登录结果，业务角色和数据权限应按接入方实际需要实现。

准备移植到自己的业务系统时，读[普通单点登录接入指南](../外部系统接入/普通单点登录接入指南.md)。
