# 示例客户端快速运行

这份文档带你启动本仓库中的示例客户端，并用【订单查询】完成一次平台登录。示例首页显示“业务系统 B”，它代表接入方系统。登录页面和认证服务由一体化平台环境提供。

## 1. 准备工具和平台信息

准备 JDK 8、Maven 和 Node.js。Node.js 满足 `frontend/package.json` 中的版本要求即可，例如 24.12 或更新的 24.x。首次打包需要能下载前后端依赖。

请平台管理员为示例登记客户端，取得客户端编号、客户端密钥、平台认证接口前缀和测试账号。初次体验可选普通单点登录，并请管理员确认该客户端关闭了平台外部账号必绑。平台无需为此模式逐页登记。想体验按页面分配权限，可选页面受控，按[页面受控示例](运行页面受控示例.md)先准备页面授权。

| 示例登记项 | 本机运行时填写 |
| --- | --- |
| 系统地址 | `http://localhost:18085` |
| 回调路径 | `/api/auth/callback` |
| 认证模式 | 普通单点登录（`SSO_ONLY`）或页面受控（`PAGE_CONTROLLED`） |

系统地址和回调路径拼成 `http://localhost:18085/api/auth/callback`。若浏览器在另一台机器上，将示例中的客户端主机换为浏览器访问的 IP 或域名，登记和配置一起改。

## 2. 配置并启动示例

从仓库根目录复制 `.env.example` 为 `.env`。已有文件时编辑现有内容。以下以普通单点登录为例。

```properties
SSO_BASE_URL=http://localhost:19089/oauth2Server/oauth2
SSO_CLIENT_ID=填写平台分配的编号
SSO_CLIENT_SECRET=填写平台交付的明文密钥
B_CALLBACK_URL=http://localhost:18085/api/auth/callback
SSO_AUTH_MODE=SSO_ONLY
SSO_REQUIRE_EXTERNAL_ACCOUNT=false
```

将首行地址换成平台管理员提供的认证接口前缀。浏览器和示例后端都需要访问该地址。使用页面受控时，把 `SSO_AUTH_MODE` 改为 `PAGE_CONTROLLED`，同时保留 `SSO_REQUIRE_EXTERNAL_ACCOUNT=false`。两项都要与平台登记方案一致。真实密钥只保存在后端，修改配置后重启后端。启用平台维护账号绑定时，按[绑定接入指南](../外部系统接入/普通单点登录接入指南（平台维护外部账号绑定）.md)准备测试账号和两端配置。

先在终端运行 `java -version`、`mvn -version`、`node -v` 和 `npm -v`，确认这些命令可用，且 Maven 使用 JDK 8。再进入仓库根目录运行以下命令。

```powershell
.\scripts\package.ps1
java -jar backend/target/sso-client-b-demo-0.1.0-SNAPSHOT.jar
```

在 Linux 或 macOS 中将首条命令换为 `bash scripts/package.sh`。打包脚本构建前端并将它与后端打到同一个 JAR（Java 应用包）。保持后端终端运行，浏览器打开 `http://localhost:18085`。

## 3. 完成一次登录并退出

1. 点击【订单查询】。首次没有平台登录状态时，浏览器将打开一体化平台登录页。
2. 使用测试账号登录。浏览器回到示例的固定回调，授权成功后显示订单页。
3. 返回示例首页，可查看平台用户摘要、当前模式和有效访问令牌数。
4. 在首页点【退出 B 系统】结束示例的本地登录。平台会话仍有效时，再进入业务页可免输密码取得新授权。要验证全局退出，先重新进入订单页取得授权，再返回首页点【退出整个服务】。平台退出完成后，下次进入订单页应要求重新登录。

首页打开后若业务页一直打不开，先检查平台地址、完整回调、客户端凭据和测试账号权限。还有问题可按[常见问题与排查](../原理与参考/常见问题与排查.md)确认问题发生在哪一步。

## 4. 修改示例前端时的运行方式

需要边改 Vue 页面边观察结果时，可分别运行前端与后端。将平台登记的系统地址及配置中的完整回调的端口同时改为 `5173`，固定回调路径保持 `/api/auth/callback`，后端监听仍是 `18085`。

第一个终端进入 `backend/`，执行 `mvn clean spring-boot:run`。第二个终端进入 `frontend/`，依次执行 `npm ci` 和 `npm run dev`。浏览器访问 `http://localhost:5173`。Vite（前端开发服务器）会把 `/api` 和 `/pages` 转发给后端。切回单 JAR 方式时，把平台登记和完整回调同步改回浏览器使用的端口。完整参数见[配置与访问地址](../原理与参考/配置与访问地址.md)。
